# Datheon Python Internship Projects

This repository contains the projects and assignments completed during the Datheon Internship.

## 📂 Projects Included

### 1. [E-commerce](./E-commerce/)
An interactive e-commerce storefront featuring product browsing, shopping cart management, responsive design, and product catalog interactions.

### 2. [Portfolio](./Portfolio/)
A personal portfolio web application with modern UI/UX, project showcase, video demonstration, resume/certificate downloads, and an Express.js backend for contact form handling.

### 3. [Task Manager CRUD Operations](./Task%20Maneger%20crud%20oprations/)
A task management application implementing full CRUD (Create, Read, Update, Delete) capabilities with status filtering and local persistence.

### 4. [Real-Time Weather](./real%20time%20whether/)
A real-time weather forecasting web application utilizing the OpenWeatherMap API to display current conditions, temperature, humidity, and forecasts.
